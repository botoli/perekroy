# ПЕРЕКРОЙ

Лендинг на React и Vite. Запуск: `npm install`, затем `npm run dev`. Сборка: `npm run build`; результат в `dist`.

Форма демонстрационная: заявки и фото никуда не отправляются. Перед запуском подключите сервер или сервис приёма заявок. Цены и контакты нужно заполнить актуальными данными. Изображения взяты из материалов заказчика.

## Шрифты

Для отображения фирменных шрифтов добавьте файлы `public/fonts/FindSansPro-Regular.woff2` и `public/fonts/PFStampsPro.woff2`. До этого используются запасные шрифты. PF Stamps Pro требует соответствующей лицензии; FindSans Pro доступен по SIL OFL 1.1, при добавлении файла сохраните текст лицензии и сведения об авторе рядом с ним.
